# 결정 기록 (ADR)

구조, 규칙, 의존성을 크게 바꾸는 결정과 그 이유를 남긴다. 규칙 자체는 `AGENTS.md`에 둔다.
다음에 이 일을 맡은 사람이 "왜 이렇게 했지?"에 답을 찾을 수 있게 하는 것이 목적이다.

## 쓰는 법

1. `template.md`를 `NNNN-slug.md`로 복사한다. 번호는 마지막 번호 다음이고, slug는 영어다.
2. 배경, 고려한 안, 결정, 결과를 짧게 쓴다. 한 화면에 들어가면 충분하다.
3. 결정을 바꾸는 PR에 함께 넣는다. 논의는 PR에서 한다.

## 고치는 법

- 쓴 ADR의 내용은 고치지 않는다. 오타와 링크만 고친다.
- 결정을 바꾸면 새 ADR을 쓴다. 옛 ADR에는 제목 바로 아래에 한 줄만 더한다:
  `> 대체됨: [NNNN](NNNN-slug.md)`.

목록 파일은 두지 않는다. 파일 이름과 첫 줄로 찾는다.
