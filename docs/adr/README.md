# 결정 기록 (ADR)

구조, 규칙, 의존성을 크게 바꾸는 결정과 그 이유를 남긴다. 규칙 자체는 `AGENTS.md`에 둔다.

## 쓰는 법

1. `template.md`를 `NNNN-slug.md`로 복사한다. 번호는 마지막 번호 다음이고, slug는 영어다.
2. 상태를 "제안"으로 두고 PR을 연다. PR에서 논의한다.
3. merge할 때 상태를 "받아들임"으로 바꾸고 아래 목록에 더한다.
4. 받아들인 ADR은 고치지 않는다. 결정을 바꾸면 새 ADR을 쓰고, 옛 ADR의 상태만
   "대체됨(→ 새 번호)"으로 바꾼다. 아래 목록에서도 옮긴다.
